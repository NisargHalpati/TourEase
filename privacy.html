Privacy Policy

TourEase is a static travel-discovery website. Account and community features use the TourEase Supabase project configured for this site.

Information and browser storage

If you register, Supabase Authentication processes your email address and password. Your display name and bio, posts, likes, and comments are stored in the configured Supabase database and shared according to its Row Level Security policies. Passwords are handled by Supabase Authentication and are not stored by TourEase browser code. Starter stories are project-provided content. Destination content is provided by project data files.

The Supabase client keeps an authentication session in browser storage so you can remain signed in. Anyone using the same browser profile may be able to access the signed-in account until you log out.

Cookies and session data

The project code does not integrate analytics. Supabase Authentication may use browser storage for your session. TourEase also uses session storage temporarily to restore Inspirations page state during navigation. Browser storage behavior and retention are controlled in part by your browser.

External content and links

The Supabase JavaScript client is loaded from jsDelivr. Some travel images are loaded from external image hosts, and a post can display an image URL entered by a visitor. Loading these resources may reveal technical request information to their hosts. Links to Instagram and GitHub take you to those services, which operate under their own privacy policies.

Retention, deletion, and security

Account and community content remains in Supabase until removed through the available site features or database administration. Logging out ends the browser session but does not delete your profile or posts. Deleting a post depends on the database relationships and Row Level Security policies configured for the project.

Profile and community data saved by an earlier browser-only version is not imported into Supabase and may remain in that browser’s local storage until cleared through the browser’s site-data settings.

Public feed content can be read by visitors. Avoid sharing sensitive information in public profiles, posts, or comments. Supabase Row Level Security policies control which account data can be changed.

Privacy questions

For privacy-related questions, email us using the contact link in the “Connect With Us” section in the footer.
